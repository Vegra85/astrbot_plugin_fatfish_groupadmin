# 鱼力max · 群管说了算

> **鱼力max 系列（鱼有分寸）**：[活人感](https://github.com/Vegra85/astrbot_plugin_fatfish_alive) · [认 AI](https://github.com/Vegra85/astrbot_plugin_fatfish_aiguard) · [看图懂梗](https://github.com/Vegra85/astrbot_plugin_fatfish_seememe) · [法庭](https://github.com/Vegra85/astrbot_plugin_fatfish_court) · [群管说了算](https://github.com/Vegra85/astrbot_plugin_fatfish_groupadmin) —— 每个都能单独用，一起装自动让路。作者 Vegra85；跟市场上其他叫「大肥鱼」的插件无关。

一句话：群主让它安静，它照样插嘴；群友说「别接我的话」，它下一句还接。装上以后反过来 —— 群里的人管机器人：群主 / 管理员说「安静点」它就只回 @，说「闭嘴」就只有管理员 @ 才回，到点自己恢复；群友说「别理我」只对他生效；被 QQ 禁言时什么都不发。

市场上的群管插件都是机器人去管群，这个是群管管机器人。

## 30 秒装好

1. 插件市场搜「鱼力max」或「群管说了算」→ 装 → 重启 AstrBot
2. 默认配置就能用；最常改的几项：
   - 「没说多久时，安静 / 静音几分钟」（默认 30）
   - 「它的名字 / 外号」（群管不 @、只叫名字也算；QQ 昵称和群名片它自己会查）
   - 「谁说了算」：群主 / 群管理员 / AstrBot 管理员，三个开关（默认都算）
3. 哪里看效果：
   - 群里发 `/说了算`：这个群现在什么状态、谁设的、还剩多久
   - AstrBot 面板 → 插件 → 群管说了算 → 打开页面：各个群的状态，能一键解除
   - 日志里搜 `[群管说了算]`

## 群里说什么

| 谁 | @ 它或叫它名字，说… | 结果 |
|---|---|---|
| 群主 / 管理员 | 安静点、少说点、别插嘴、安静一小时、安静到晚上 | 这个群进「安静」：只回 @ 它和引用它的 |
| 群主 / 管理员 | 闭嘴、别说话、禁言半小时 | 这个群进「静音」：谁都不回，只有群主 / 管理员 @ 它才回 |
| 群主 / 管理员 | 可以说话了、恢复、别安静了 | 马上恢复（群主设的，群管理员撤不掉，见下面「分高低」） |
| 群主 / 管理员 | `/说了算 解除` | 马上恢复（QQ 禁言的记录也一起清掉；同样分高低） |
| 任何人 | 别理我、别接我的话、别 @ 我 | 只对他：他没 @ 它、没引用它的话，它不主动接（默认 24 小时） |
| 他本人 | 可以理我了、理理我 | 撤掉 |
| QQ | 把它禁言 / 全员禁言（它不是管理） | 这个群什么都不发；解禁通知一来马上恢复，通知漏了也会去 QQ 查 |

时长按他说的：「一小时」「半小时」「十分钟」「1h」「到晚上」「到明天」「到 8 点」「今晚」都认；没说就用默认（30 分钟）；最长 24 小时（可配）。
「到 12 点」：没说上午 / 晚上时，还没到中午就是中午、过了中午就是半夜；「晚上 12 点」「夜里 12 点」「到零点」都是半夜。

不算让它安静的（就算 @ 了它）：问句（「安静点？」「谁把小王禁言了？」—— 拿不准，默认不改）、转述别人的话（「他刚说让你闭嘴」「让你闭嘴的是群主」）、说别人的禁言（「帮我禁言他」「刚才有人被禁言了」）、说自己的事（「我手机静音了」）、玩笑（「别说了笑死我了」「安静点哈哈哈」）。

### 分高低（谁设的谁撤）

身份从低到高：群管理员 < 群主 < AstrBot 管理员。

- 身份高的人设的安静 / 静音，身份低的人**撤不掉、改不松**：群主设的「静音」，群管理员说「可以说话了」或者让它改成「安静」都不算（它照回这一句，模型知道「撤不掉，状态没变」）；群主自己、AstrBot 管理员可以撤。
- **往严了改谁都可以**：群主设了「安静」，群管理员说「闭嘴」→ 加一层「静音」；到点（或者群管理员自己撤掉）以后回到群主的「安静」，不会直接恢复正常。
- 身份一样的人：后说的算。`/说了算` 和面板里能看到现在是哪一层、下面还压着谁设的哪一层。

它怎么回「安静点」这一句，由模型自己说 —— 插件只把事实告诉它：谁、让你怎样、到几点。想让群里有个明确的回执，打开「改了状态时发一句系统提示」（默认关）。

## 常见问题

1. **群友说「安静点」怎么不管用？** 只认群主、群管理员、AstrBot 管理员（看 QQ 给的身份）。嘴上说「我是管理」不算。模型那一轮会知道「他说的不算，状态没变」。
2. **说「你们安静点」它没反应？** 没 @ 它、没叫它名字的不算（多半是在说别人）。@ 它，或者在配置里填上它的外号再叫名字。
3. **「可以说话了吗」「你怎么还不安静」不管用？** 问句规则拿不准，就不改。想让它也认：打开「规则拿不准时问一次模型」（改不改、谁有权改还是按身份卡，模型说了不算）。
4. **都安静了，它还在群里冒出一句？** 多半是活人感的冷场试探 / 收尾潜水，见上表。
5. **禁言解了，它还是不说话？** 解禁通知漏了也有兜底：开机、NapCat 重新连上时查一遍各个群；之后每 10 分钟去 QQ 查一次记着在禁言的群（它自己的 `shut_up_timestamp`、群的 `group_all_shut`）；全员禁言时有普通群友说话就当解了。急的话群主 / 管理员发 `/说了算 解除`。
6. **群主设的安静，管理员怎么撤不掉？** 分高低，见上面。群主自己、AstrBot 管理员可以撤；群管理员只能往严了加。
7. **私聊发 `/说了算` 看到的是什么？** AstrBot 管理员看到各个群的状态；别人只看到自己在哪些群说过「别接我的话」（看不到群号列表、看不到别人）。

## 工作原理

- **认话**（规则，不花钱）：群管的话要冲着它说（@ 它 / 引用它 / 叫它名字），说法有安静、静音、恢复三组；「静音」「禁言」只认命令的说法（「静音」「你静音吧」「禁言一小时」），「我手机静音了」不算。挡掉的反例：「你们安静点」（没点名）、「我先安静会儿」「我手机静音了」（说的是他自己）、「让他们安静点」「帮我禁言他」「刚才有人被禁言了」（说的是别人）、「他刚说让你闭嘴」「让你闭嘴的是群主」（转述）、「不是让你闭嘴」、「别说了笑死我了」「安静点哈哈哈」（玩笑）、「好安静啊」「安静的夜晚」（是描述）、问句（「安静点？」「谁把小王禁言了？」「为什么要我闭嘴」，拿不准）。「别吵我」「别跟我说话」算他管自己，不让整个群安静。
- **谁说了算**：只看 NapCat 每条群消息带的 `sender.role`（owner / admin）和 AstrBot 的管理员名单；分高低时取他最高的那个身份。状态按层存：每层记着谁设的、什么身份、到几点，压在下面的那层到点前一直在。
- **拦**：`on_waiting_llm_request`（优先级 2000000：认 AI 之后、活人感之前）。被禁言 → 谁都不回；静音 → 只有群管 @ / 引用它才放行；安静 → 只有 @ / 引用它（或用唤醒词）才放行；「别接我的话」→ 他没 @ / 引用它的不放行。拦之前替天使之心收口。群管改安静 / 静音的那一句本身放行（改成了、没改成都算），让模型回；群友的「别理我」「可以理我了」照样过静音 / 安静的拦（不然静音中谁都能拿这几句让它开口、还能来回刷），这时插件的系统提示也不发。
- **只叫名字的群管命令**：AstrBot 不会因为叫名字就叫醒模型，本插件替它叫醒，让模型回这一句（「别接我的话」不叫醒：人家不想被接话）。
- **每一轮给模型的状态**：`on_llm_request` 里加一段临时的（不进对话记录、不改系统提示）：这个群现在安静 / 静音、谁几点设的、到几点；谁说了别接他；刚解禁。只写事实，不写台词。
- **QQ 禁言**：收 NapCat 的 `group_ban` 通知（`user_id` 是它 = 它被禁言，带时长；`user_id` 是 0 = 全员禁言，它是群主 / 管理时不算）。通知没带时长时不瞎猜，去查它自己的 `shut_up_timestamp`（查不到先停 10 分钟再查）。通知会漏（重启、掉线的时候来的）：开机、NapCat 重新连上（`lifecycle.connect`）时用 `get_group_list` + `get_group_member_info` 对一遍所有群，之后每 10 分钟对一遍记着在禁言的群、每 6 小时对一遍所有群。禁言中 `on_decorating_result` 把要发的都清掉（指令回复、别的插件的话也算）。它自己的禁言和全员禁言分开记，解了一个另一个还在。
- **到点恢复**：读状态时过了点就当没有（重启、卡一会儿都不会多关它）；后台每 20 秒清一次过期的、记一笔。
- **给别的插件用的公开方法**（duck typing：`context.get_registered_star("astrbot_plugin_fatfish_groupadmin").star_cls`）：
  - `group_state(group_id, platform_id="")` → `{"mode": "quiet" / "mute" / None, "until": 到几点, "banned": 禁言着没有}`
  - `may_speak(group_id, user_id="", addressed=False, platform_id="", admin=False)` → `(能不能说, 为什么)`

## 全部配置

| 配置 | 默认 | 说明 |
|---|---|---|
| 开启 | 开 | 总开关 |
| 没说多久时，安静 / 静音几分钟 | 30 | 说了「一小时」「到晚上」就按他说的 |
| 安静 / 静音最长几小时 | 24 | 「以后都别说了」「闭嘴三天」也最多这么久 |
| 群友「别接我的话」管几小时 | 24 | 他说了多久按他说的（最长 7 天） |
| 群主说了算 / 群管理员说了算 / AstrBot 管理员说了算 | 都开 | 关掉哪个，哪个说的就不算 |
| 它的名字 / 外号 | 空 | 叫名字也算冲它说；QQ 昵称和群名片自己查；至少 2 个字 |
| 规则拿不准时问一次模型 | 关 | 每个群每小时最多 10 次；同一句 10 分钟内不重复问 |
| 拿不准时问哪个模型 | 空 | 空 = 这个群当前的对话模型 |
| 改了状态时发一句系统提示 | 关 | 插件自己发「（系统提示）本群进入「安静」，到 14:32……」 |

## 已知限制

- 认的是常见的中文说法（几十种 + 反例），不是所有说法都认得；问句、反话、又让安静又让恢复的，默认不改（可开模型判断）。
- 安静 / 静音只管模型回话（包括 AstrBot 主动回复、接话类插件）；别的插件的指令回复、关键词回复照常。被 QQ 禁言时例外：经过「发送前」那一步的都不发。
- 别的插件用 `context.send_message` 直接发的（比如活人感的冷场试探 / 收尾潜水）不经过模型请求和「发送前」，拦不住。
- 「别接我的话」只管「主动接」：他 @ 它、引用它照回；只叫它名字不算 @。
- 分高低只认三档身份（群管理员 < 群主 < AstrBot 管理员），不认群头衔、等级。
- 时间按 AstrBot 配置里的时区；没配、配错、这台机器没有时区数据时按北京时间（不退回服务器的时区 —— 服务器常常是 UTC）。「到晚上」按 18 点（已经晚上了按 23 点）、「到明天」按早上 8 点、「今晚」到明早 7 点、「今天」到 24 点。
- 全员禁言要知道它在群里的身份：查不到就当它是普通群员（会停发，等解除 / 有普通群友说话 / 24 小时）。
- 只支持 QQ（aiocqhttp / NapCat），AstrBot ≥ 4.29。状态存在 `data/plugin_data/astrbot_plugin_fatfish_groupadmin/state.json`。
